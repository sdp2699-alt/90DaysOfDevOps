# 90 Days of DevOps – Personal Learning Plan

## 1. Current Level
- **Role / Background:** Working Professional (DevOps Engineer)
- **Current Focus:** Strengthening core DevOps automation, cloud infrastructure, and production troubleshooting skills.

## 2. Understanding of DevOps & Cloud Engineering
DevOps is a culture and set of practices that bridges software development and IT operations to deliver reliable software faster through automation, CI/CD, and continuous feedback. Cloud Engineering provides the scalable, on-demand infrastructure and managed services needed to run and automate these modern workloads efficiently.

## 3. Why I Am Starting #90DaysOfDevOps
I want to build deep, hands-on consistency across the end-to-end DevOps lifecycle—moving beyond isolated tasks to mastering how K8s, containers, CI/CD, Infrastructure as Code, and cloud platforms work together in production.

## 4. Where I Want to Reach (90-Day Vision)
In 90 days, I want to be confident in architecting, automating, deploying, and monitoring production-grade cloud-native applications from scratch with minimal manual intervention.

## 5. 3 Clear Goals for the Next 90 Days
1. Build and automate end-to-end CI/CD pipelines for containerized applications.
2. Provision and manage multi-environment cloud infrastructure using Terraform.
3. Deploy, scale, and troubleshoot a production-grade microservices application on Kubernetes.

## 6. 3 Core DevOps Skills I Will Build
1. **Linux & Shell Scripting:** System administration, networking, and automating repetitive operational tasks.
2. **Containers & Orchestration:** Docker image optimization and Kubernetes deployment/debugging.
3. **Infrastructure as Code (IaC) & CI/CD:** Writing modular Terraform code and automating builds/deployments.

## 7. Weekly Time Budget & Consistency Plan
- **Weekdays (Mon–Fri):** 2 hours/day (1 hour hands-on lab + 1 hour documentation/notes)
- **Weekends (Sat–Sun):** 4–5 hours/day (building weekly mini-projects and reviewing concepts)
- **How I Will Stay Consistent:**
  - Commit and push my progress to GitHub daily before ending my study session.
  - Share weekly learnings on LinkedIn to stay accountable.
  - Focus on small, daily hands-on execution rather than passive watching.
